# Dataset registry: what we may train on, and why

**Plan v2, Track C, step C2** (brief §16). Every dataset the project trains or evaluates on is listed here **before** it's used. Each entry gives its licence, what we must do in return, and the exact version used. The version and the SHA-256 fingerprint are filled in when the files are first downloaded. A dataset not on this page may not be used.

**Status:** first draft, 12 November 2026. Nothing is downloaded yet. The licences were read on 12 November 2026 in research R002 ([training notes](../docs/research/R002-fresh-plan/notes/small_model_training_mac.md), [Indic notes](../docs/research/R002-fresh-plan/notes/indic_languages_coding.md)), and are re-read from the dataset's own page on the day it's downloaded.

## In plain words

Training a model on text you're not allowed to use can make the model itself unusable for a business. So every source gets three checks:
1. **Does its licence allow commercial use?**
2. **What do we owe in return?** Usually credit (attribution), sometimes passing the terms on.
3. **Can we prove later exactly which files we used?** That's the version and fingerprint.

"Excluded" means we don't use it at all, even for research, so a later commercial model can never be contaminated by it.

## Excluded

| Dataset | Why |
|---|---|
| **Samanantar** (`ai4bharat/samanantar`) | CC-BY-NC-4.0: no commercial use. |
| **BPCC's "existing mined corpora" part** | It repackages Samanantar under CC0, which conflicts with Samanantar's own non-commercial licence. Not used until AI4Bharat resolves the conflict. |
| **The Stack v2** and **Python-Edu** | Bulk access needs a Software Heritage/INRIA agreement. Their training principles expect the resulting model to be openly licensed, with its training files published by identifier. That doesn't fit a model we might keep closed. |
| **Swecha "Chandamama Kathalu"** | CC-BY-NC-SA-4.0: no commercial use. |
| **Cosmopedia** (synthetic text) | Generated by another company's model; the card states no terms for those outputs. |
| **NVIDIA Nemotron Indic pretraining data** | Gated, owner-approved, under NVIDIA's own data agreement. Not read in full. |

## Rules

1. **Before the first download**, re-read the licence on the dataset's own page and note the date here. If it differs from this page, stop and log a decision.
2. **Pin the exact version**: the Hugging Face commit hash (`revision`), plus a SHA-256 of every downloaded file in a manifest committed beside the experiment.
3. **Keep provenance**: for code, keep each file's repo name and licence, so an attribution file can be generated.
4. **Evaluation sets never enter training data.** Check for overlap before any run whose result is published.
5. **Anything unverified** (marked in **bold** above) is resolved before the dataset is used in a result we publish.
